# eunwon-resourcepack
Minecraft Java 26.3 은원록 (무협 전투) 리소스팩 배포

서버가 접속할 때 알아서 받게 하는 팩입니다. 기본 Minecraft 26.3 클라이언트에서 동작합니다.

## 글꼴
팩에 포함했거나 글자 그림을 만드는 데 쓴 글꼴이며, 모두 SIL Open Font License 1.1을 따릅니다.

- East Sea Dokdo (`font/dokdo.ttf`)
- Gowun Batang (`font/gowun.ttf`)
- Black Han Sans (`font/black.ttf`)
